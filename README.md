Data Science & AI Engineering Study Tracker
Welcome to my personal learning repository. This space serves as a daily tracker, code archive, and experimental sandbox as I build a solid foundation in Machine Learning and Data Science.

My ultimate goal is to become an expert in the AI Engineering field, and this repository documents the daily progress and code required to achieve that.

What is this repository about?
This repository contains all the daily code, notes, and experiments I write while studying. Everything you see here represents hands-on practice, debugging, and implementation of fundamental concepts.

Currently, my learning path is strictly guided by two comprehensive resources:

The Python Data Science Handbook – Mastering the core Python data stack (NumPy, Pandas, Matplotlib, Scikit-Learn).

Essential Math for Data Science – Building the mathematical intuition (Linear Algebra, Calculus, Probability, and Statistics) required to understand machine learning algorithms under the hood.

Repository Structure
Here is a breakdown of the current directories and what you will find inside them:

Maths/
Contains notes, formulas, and Python implementations of mathematical concepts crucial for Data Science.

ipython/
Interactive computing experiments and scratchpad notebooks where I test out quick ideas, snippets, and Python behaviors.

numpy-data_science_handbook/
Dedicated entirely to mastering NumPy. Contains daily exercises on array programming, broadcasting, vectorization, and manipulating numerical data efficiently.

pandas-data_science_handbook/
Focused on data manipulation. This directory holds my practice code for data cleaning, grouping, merging, and time-series analysis using Pandas.

My Daily Workflow
To ensure consistent progress, my daily routine follows this structure:

Study: Read a chapter or section from my core books.

Code: Translate the theoretical concepts into actual Python code or Jupyter Notebooks.

Experiment: Tweak the code, break it, and fix it to understand the boundaries of the libraries I am using.

Commit: Push the daily files to this repository to maintain a strict record of my consistency.
